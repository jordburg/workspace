# Third-party notices

## Cburnett chess pieces

The files named `ChessPiece*.svg` in `WorkspaceHealth/Assets.xcassets` use the
classic SVG chess pieces by Cburnett. The artwork is available from
[Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces)
under the
[Creative Commons Attribution-ShareAlike 3.0 Unported license](https://creativecommons.org/licenses/by-sa/3.0/).

Workspace generated these standalone SVG files from the default piece renderers
bundled with `react-chessboard` 5.12.1. The conversion changed the outer SVG
width and height from percentages to 45 units for the Xcode asset compiler. It
did not change the piece geometry or colors.
